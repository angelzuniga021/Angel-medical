# Ángel Medical PC 1.0

Windows 10/11 x64. Aplicación independiente generada desde el mismo código
clínico Flutter de Android. No necesita un respaldo para iniciar.

## Instalación

El instalador Inno Setup entrega la aplicación, Flutter, SQLCipher 4.6.1,
OpenSSL con sus proveedores, PDFium y runtime C++ en la carpeta del programa.
No requiere Python, Java ni SDK en la PC del usuario. La base se guarda en
LOCALAPPDATA/AngelMedical/databases, fuera del directorio de instalación.
No se empaqueta ni sustituye una base de producción. Cada usuario configura
su PIN, perfil, establecimiento y logos o importa un .ambak existente.

## Módulos

Pacientes, historia, consultas, urgencias, hospitalización, evoluciones,
indicaciones, egreso, recetas, documentos, escalas y calculadoras, tareas,
adjuntos, agenda, perfiles/logos, impresión, respaldos y firma electrónica.
Se conserva la interfaz adaptable con navegación lateral en pantallas grandes.

## Respaldo

El mismo contenedor .ambak v2 de Android: AES-GCM-256 con clave derivada por
PBKDF2-HMAC-SHA256, 150000 iteraciones. Incluye la base SQLCipher y su clave
solo dentro del contenedor cifrado. Importación/validación acepta esquemas
hasta 7 y verifica relaciones, conteos, adjuntos y estructura clínica.
APK 3.2.2 corrige el límite anterior de validación que rechazaba schema 7.

Guardar respaldo en PC abre Guardar como y permite elegir la carpeta Drive.
Restaurar es sustitución completa validada con copia previa de emergencia;
no combina registros ni sincroniza dos equipos. No restaurar un respaldo de
un dispositivo sobre otro con cambios nuevos sin revisar y guardar ambos.

## Firma

OpenSSL incluido produce y verifica CMS y firma integrada en recetas PDF.
Contraseña por stdin; no se pasa en argumentos de proceso. Solo se escriben
archivos temporales de la clave PKCS8 ya cifrada, eliminados al terminar.
Nunca se guarda la clave privada o su contraseña en la base. Conserva las
limitaciones de confianza SAT, revocación y sello de tiempo de Android.
La revisión documental no acredita certificación NOM.

## Agenda

Recordatorios dentro de la aplicación mientras permanece abierta. No se
instalan servicios ni tareas de Windows; alertas con el programa cerrado son
una función posterior y no se presentan como completadas.

## Pruebas

Se reutilizan las pruebas clínicas y PDF de Android. Pruebas Windows reales:
base cifrada, rechazo de clave incorrecta, persistencia después de reabrir,
edición CRUD, .ambak esquema 7, perfil/logo, adjuntos y escala cero, rechazo
schema 8, OpenSSL con clave PKCS8 cifrada, firma PDF y rechazo de alteraciones.
Instalación silenciosa en carpeta de prueba, creación de base independiente,
arranque del ejecutable y reinstalación comprobando la huella de la base.
Todas las pruebas usan datos ficticios. La aceptación con el respaldo real del
médico se realiza en su PC; no publicar información clínica en GitHub.

## Fuentes de compilación

Ejecutar python tools/prepare_desktop.py copia módulos, assets y pruebas y
aplica adaptaciones de plataforma. El workflow Angel Medical PC completo
compila SQLCipher de fuente oficial v4.6.1, prueba y empaqueta el instalador.
