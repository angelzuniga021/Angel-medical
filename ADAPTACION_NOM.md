# Angel Medical 2.2: adaptación documental

Referencia consultada el 30 de septiembre de 2026: NOM-004-SSA3-2012. Esta versión facilita registrar apartados; **no declara ni certifica cumplimiento integral**. La captura clínica, las firmas y los procedimientos del establecimiento siguen siendo necesarios.

| Área | Función implementada | Límite que debe revisarse |
|---|---|---|
| Identificación, apartados 5.2, 5.9 y 5.10 | Datos del paciente, autor y establecimiento conservados por nota; fecha/hora de atención y registro separadas. | Veracidad, exactitud, identificación real del responsable y firma. |
| Historia, apartado 6.1 | Tipo historia inicial; antecedentes, interrogatorio por sistemas, exploración, mediciones, resultados, diagnóstico, pronóstico y terapéutica. | Los campos abiertos no verifican que la exploración y el contenido sean suficientes; grupo étnico se registra cuando aplica. |
| Evolución ambulatoria, apartado 6.2 | Tipo diferenciado; evolución, estudios, diagnóstico, pronóstico y tratamiento. | El médico decide qué signos necesita obtener y documentar; la app no emite decisiones clínicas. |
| Urgencias e ingreso, apartados 7.1 y 8.1 | Pronóstico, interrogatorio, exploración y mediciones; motivo explícito si no se obtuvo una medición. | Excepciones documentadas requieren valoración, seguimiento y revisión del establecimiento. |
| Evolución hospitalaria, apartado 8.3 | SOAP con diagnóstico, resultados, pronóstico y terapéutica; consulta e impresión completas. | No vigila automáticamente el mínimo de una evolución diaria. |
| Referencia e interconsulta, apartados 6.3 y 6.4 | Documentos con establecimiento emisor/receptor, motivo, diagnóstico, terapéutica y campos de interconsulta. | No transmite ni confirma recepción en otra institución. |
| Egreso, apartado 8.9 | Nota independiente vinculada al ingreso, motivo, diagnósticos, resumen/estado actual, manejo, pendientes, plan, vigilancia, riesgos y pronóstico. | En defunción deben revisarse causas y necropsia; no reemplaza un certificado de defunción. |
| Consentimiento y egreso voluntario, apartados 10.1 y 10.2 | Campos y espacios para firma del paciente/representante, médico y dos testigos. | Son documentos preparados para firmarse, no constancias de consentimiento otorgado. Deben adecuarse al acto específico y al establecimiento. |
| Conservación, apartado 5.4 | Archivado sin borrado definitivo y respaldos; migración aditiva. | El responsable debe asegurar disponibilidad y conservación efectiva mínima de cinco años desde el último acto médico, o mayor si procede. |
| Correcciones | Antes/después, motivo, responsable y fecha de corrección; conservación de fecha y autor originales. | No equivale a una bitácora certificada o inviolable. |
| Expediente electrónico, NOM-024 | Se mantienen cifrado, respaldo e integridad local; no se atribuye certificación. | Pendientes revisión formal de aplicabilidad, evaluación de conformidad, interoperabilidad, gestión de acceso, autenticación y firmas jurídicamente válidas. |

Las notas previas permanecen con sus datos existentes. No se agregan fechas, firmas ni autorías retrospectivas. Una corrección de nota antigua se identifica como tal.

Los PDF muestran la firma autógrafa pendiente. Deben recabarse las firmas, conservarse los originales y adjuntarse copias identificadas. No basta con insertar una imagen de firma para resolver una firma electrónica válida.

Las recetas no sustituyen una nota de evolución. El formato de prescripción general tampoco acredita cumplir requisitos especiales para medicamentos sujetos a control.

Las reglas de completitud pueden pedir más documentación que el mínimo aplicable a una atención particular. No evalúan la calidad ni el sentido clínico del texto. Las ausencias de información no se rellenan con valores inventados: se mantienen borradores y, para mediciones, se permite registrar el motivo.
